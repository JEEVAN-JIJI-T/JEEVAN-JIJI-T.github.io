# Jeevan Jiji Thomas — Enhanced Interactive Portfolio

This version combines the richer visual language and effects from the supplied reference website with the previously built portfolio.

## Latest iteration
- Loading screen is intentionally held for 2 seconds.
- Capability orbit uses deterministic geometry so all five nodes remain centered on the JJT core and move smoothly around it.
- Orbit nodes are not clickable; pointer proximity makes them glow.
- Project cards use distinct visual systems rather than repeating the same card artwork.

## Included
- Large smooth capability orbit around the JJT center
- Orbit nodes are non-clickable; they glow when the pointer approaches/interacts with them
- Multiple animated orbital rings, halo, satellites and pulsing core
- Preloader and orchestrated hero reveal
- Ambient particle field and noise texture
- Cursor spotlight
- Scroll progress indicator and navigation depth
- Smooth anchor scrolling
- Magnetic buttons
- 3D project-card tilt
- Scroll-triggered reveals
- Animated project artwork
- About stats, project grid, journey timeline, TEDx feature, toolkit, philosophy and contact sections
- Responsive mobile navigation and layout
- Reduced-motion accessibility support

## Run
Open `index.html` directly or use VS Code Live Server / `python -m http.server`.

## Deploy
Works on standard static hosting such as GoDaddy, Hostinger, GitHub Pages, Netlify or Cloudflare Pages.

## Note
Replace `hello@jeevanjiji.dev` in `index.html` with the professional email address you want to publish.
